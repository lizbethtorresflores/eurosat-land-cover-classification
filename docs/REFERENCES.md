# Referencias y contexto / Références et contexte

## Données EuroSAT

- [EuroSAT multispectral — Zenodo, enregistrement 7711810](https://zenodo.org/records/7711810) : source des images utilisées dans l’étude.
- [Archive EuroSAT_MS.zip](https://zenodo.org/records/7711810/files/EuroSAT_MS.zip) : archive téléchargée par le notebook.

Le jeu utilisé comprend 27 000 patches Sentinel-2, dix classes, 13 bandes et des images de 64 × 64 pixels. Le dataset complet est exclu du dépôt. Les figures RGB présentées dans le README proviennent de ces données, avec ajustement du contraste pour l’affichage.

## Travail académique

Ce travail a été réalisé **en groupe à partir d’un notebook de cours**. Le fichier [projet_a_eurosat_g1_COMPLET_FR.ipynb](../projet_a_eurosat_g1_COMPLET_FR.ipynb) conserve la trame pédagogique et présente les explications, l’exploration, l’extraction de caractéristiques, le protocole spatial, la pipeline, les résultats et l’analyse des limites.

Le dépôt est présenté sur le profil de **Lizbeth Alexandra Torres Flores**. Les données EuroSAT et le support pédagogique constituent les sources du travail ; les informations disponibles ne précisent pas les noms de l’enseignant et des autres membres du groupe.
